2. Objeto

Esta web tiene como finalidad dar a conocer los servicios de AquaLadra y permitir reservar cita en la peluquería. El acceso es gratuito, salvo el coste de la conexión a internet de cada persona.

Al utilizar esta web se acepta este aviso legal. Si no se está de acuerdo con alguno de sus puntos, basta con no utilizarla.

3. Uso de la web

Quien visita esta web se compromete a:

  • Facilitar datos veraces al reservar una cita.
