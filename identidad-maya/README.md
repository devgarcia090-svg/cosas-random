# Identidad de Maya · Club PPP

Propuesta de identidad visual para Maya, el Rottweiler Peluche. Abre
`index.html` en el navegador para ver el manual completo.

**Concepto:** Maya preside un club. Las siglas que la ley usa para señalar a
estos perros, PPP (Potencialmente Peligroso), pasan a significar **Puro Perro
Peluche**. La burocracia PPP (licencia, registro, bozal) se convierte en
carnet de socio, número de socio e insignias.

## Qué hay

- `svg/logo-*`: logotipo «Maya.» (Bagel Fat One a curvas, punto en fuego) y
  versión horizontal con isotipo.
- `svg/isotipo*`: la cabeza de Maya (cejas fuego y lengua fuera) a color,
  como pegatina para fondos oscuros y a una tinta.
- `svg/sello-club-ppp.svg`: sello del club para merch.
- `svg/favicon.svg`: icono para la web y avatar de redes.
- `svg/personaje-*`: la junta directiva (Rottweiler, Pit Bull, Dogo, Staffy, Akita).
- `svg/forma-*` y `svg/patron-*`: formas y patrones de fondo.
- `img/maya-carnet.webp`: recorte de `sitio-recuperado/fotos/maya-retrato.webp`.

## Regenerar los SVG

Todo sale de `herramientas/generar-identidad.py`:

    pip install fonttools
    python3 herramientas/generar-identidad.py

Paleta: negro `#0D0B09`, fuego `#C8722A` y crema `#F2EDE6` (los de la web), más
lengua `#F28CA5`, parque `#1F5C45` y oro `#F2B544`.
Tipografías: Bagel Fat One (marca), Bebas Neue (lemas), Montserrat (texto).
